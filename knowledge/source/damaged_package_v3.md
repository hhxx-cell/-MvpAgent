# 包裹破损处理规则（第 3 版）

## 适用范围

[p-001] 本政策自 2026-06-01 起生效，适用于示例商城的合成订单。

## 核心规则

[p-002] 发现外包装破损后 72 小时内反馈并保留照片。

## 办理条件与例外

[p-003] 先核对订单和物流节点，再记录破损部位与商品情况。 无法确认损坏责任时应转人工核验，不得直接承诺赔付。
