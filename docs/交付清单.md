## 验收用例

1. `demo-user-a` 问“退货政策是什么”，得到最新文档名、段落和生效日期。
2. `demo-user-a` 问“我上个月消费了多少元”，数值与 SQLite 对账一致。
3. 查询 `O00001` 的状态和物流，看到退款失败/运输异常；不提交确认时没有工单。
4. 使用同一会话的 `action_id` 确认，只生成一个工单；重复确认返回同一结果。
5. `demo-user-b` 查询 `O00001`，得到“未找到或无权访问”。
6. 缺少订单号时只澄清，工具调用为零。
7. 多语句、写语句、`SELECT *`、CTE/UNION 绕过、越权与文档注入被拦截。
8. 429、500 与超时在重试预算内降级；确认后的建单失败只报告“待提交”，Outbox 恢复可复验。
9. 每条 SSE 以 `done` 或稳定 `error` 结束，Trace 和指标不包含密钥、高敏个人信息。
